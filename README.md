# MSS Facility Configuration Wizard v2.0

## Purpose
Creates and edits portable `.mss` facility setup files.

## GitHub Pages installation
Upload these files to the root of the `MSS-Facility-Configuration` repository:
- `index.html`
- `README.md`
- `RELEASE_NOTES.md`
- `TM-Fieldhouse-Starter.mss`
- `blank-facility-template.mss`

Then use **Settings → Pages → Deploy from a branch → main → /root**.

## TM Fieldhouse workflow
1. Open the Wizard.
2. Click **Load TM Fieldhouse Starter**.
3. Confirm all hours, spaces, and booking labels.
4. Run Validation.
5. Export the final `.mss` file.
6. Send that file to TM with the Utilization Dashboard link.
